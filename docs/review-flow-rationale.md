# 来店客フロー再設計（案I「宛先を選ぶ」）— 前提と成立ロジック

公式サイト（LP）の訴求を検討するための前情報。2026-08-25 時点。
一次情報は `docs/handoff.md`（2026-08-23 の記録）。参照：support.google.com/contributionpolicy/answer/7400114

---

## 0. 製品の概要

**GOOD REVIEW** — 実店舗向けの「Googleレビュー獲得 × 顧客満足度アンケート」SaaS（株式会社UTUTU）。
来店客は卓上POPの二次元コードを読み、5段階評価に答える。AIがクチコミの下書きを作り、
本人がコピーしてGoogleマップに投稿する。店舗側には集計・回答一覧・多店舗管理の管理画面が付く。

---

## 0-2. 製品の思想（2026-08-26、天真が言語化。洋輔さん承認済み）

**「選別することなく、選択させる」。and の考え方であって、or ではない。**

- 良い口コミ ＝ 広めたいという気持ちの受け皿
- 悪い口コミ ＝ お客のはけ口ができ、店舗は意見が聞ける
- この2つは**両立する（and）**。★で振り分けるのは or の発想であり、採らない

**やらないこと**

- 良い口コミをハックして増やすツールにはしない。それはただのハックで、適正ではない
- 頑張っていない店舗がハックさえすれば高評価を得られるプロダクトにはしない
- 利用者にとっても、ハックで得た星を見て行ってハズレを引くのは害

**届けたい相手**

- 本当に美味しいものを出している店、技術力の高いクリニックなど、**仕組みさえ整えば良さが適正に伝わる**ところ
- 「口コミ対策はした方がいい」とほとんどの経営者が分かっている時代だが、**面倒くさすぎる**。
  わざわざお願いしないといけないし、勝手に書かれたと思ったら報復のようなレビューで、
  たまたまその時だけのことが尾を引いてしまう
- **頑張っているのにシステムのせいで困っている人を救うツール**でありたい

**この思想が、以下すべての判断の上位にある。**
迷ったら「これは選別か、選択か」「これはハックか、適正化か」で判断する。

## 1. 何を変えたか（一言で）

**「ツールがお客様を振り分ける」のをやめて、「お客様が自分で宛先を選ぶ」形にした。**

| | 旧（現行の稼働版） | 新（案I・デザイン確定済み） |
|---|---|---|
| 分岐の位置 | **星をつけた直後**。★4〜5だけGoogleへ、★1〜3は店内アンケートへ | **アンケートを書き終えた後**。全員に同じ2つの扉を出す |
| 誰が決めるか | **お店側のシステム** | **お客様本人** |
| 店に届く声 | ★1〜3のぶんだけ | **全員ぶん** |

画面の流れ（通る画面は★の数で違うが、**最後は全員が同じ「宛先を選ぶ」画面に来る**）

```
★5・4  : 評価 → 良かった点     → 宛先を選ぶ → AI下書き（Googleを選んだ場合）
★3・2・1: 評価 → 改善アンケート → 宛先を選ぶ → サンクス（お店に届けた場合）
```

「宛先を選ぶ」画面は、同じ大きさ・同じ形の2枚のカード。

- **Googleにも投稿する** … 「Googleマップに公開されます」
- **お店にだけ届ける** … 「代表が直接読みます」

下部に「どちらを選んでも、ご回答はお店に届いています」。

---

## 2. なぜ変えたか（前提＝Googleの規約）

- Googleの禁止事項に「**顧客から選択的に高評価レビューだけを募ること**」（review gating）が明記されている。
- **2026年4月16〜17日に運用が強化**され、「満足度を聞いてから選別して誘導する方式も違反（丁寧な表現でも同じ）」と
  明文化された。Gemini搭載の自動検出（レビューの急増・共有デバイスからの投稿・**似た文面**）で見つかる。
- 罰則は段階的：レビュー削除 → **そのお店の既存レビューが全部非表示** → **プロフィールに公開の警告バナー**。
- 重要な事実：**判定は「Googleリンクの大きさや置き場所」ではなく「フローの構造」**。
  リンクを小さくしても構造は変わらず、むしろ「隠す意図」の証拠が増えるだけ。

→ つまり **★で分岐している時点で定義に当たる**。ここが再設計の出発点。

---

## 3. なぜ案Iなら成立するのか（適法性の理屈）

違反は次の**3つが揃ったときだけ**成立する。

1. **事業者が主体で**
2. **満足度を基準に**
3. **勧誘に差をつける**

案Iは、**選ぶのがお客様本人**なので①を満たさない。全員に同じ2つの扉を同じ大きさ・同じ言葉で出すので②③も満たさない。
構造としては**レジ横のご意見箱**と同じ。ご意見箱があること自体は違反ではないし、
お店に直接言うか地図に書くかを客が選ぶのも違反ではない。

### 恒久の設計ルール（急所）

- **2つの扉に「どちらが良いか」を一切書かない。事実だけを書く。**
  - ○「Googleマップに公開されます」／「代表が直接読みます」
  - ✕「**ご不満の方は**こちら」← 扉に感情の向きを紐付けた瞬間、①②③が揃って違反になる
- 扉の文言は必ず**用途**で書く。**感情や満足度で書かない。**

---

## 4. なぜそれでも「良い評価はGoogle、不満はお店」に分かれるのか

製品の核心。**誘導しなくても、動機が違うので自然に分かれる。**

| 喜んでいる人が、なぜお店にではなくGoogleへ | 怒っている人が、なぜGoogleではなくお店へ |
|---|---|
| お礼は**もう済んでいる**（その場で「おいしかった」と言った） | 求めているのは報復ではなく**「解決」**（次は直してほしい） |
| うれしさの宛先は**「まだ知らない誰か」**（店主への私信ではなく推薦） | Googleは**届くか分からない**（店主が読むとは限らない） |
| **お店のためになる**と分かっている（応援のいちばん効く出し方） | **もう半分、言えている**（書いた時点で気持ちが収まりはじめる） |

**「振り分けをやめても結果はそう変わらない。ただし合法で、しかも店に届く声は全員ぶんに増える」** — これが案Iの主張。

---

## 5. 副産物（訴求として強い）

- **AIの下書きが「本人の言葉の清書」になる。** 全員が先にアンケートを書き終えているため、
  AIに渡す材料が「★の数＋選んだタグ」だけでなく**本人が書いた言葉**になる。
  - Googleが求める "genuine experience（実体験）" に合致する
  - **似た文面の自動検出にも強くなる**
- **お店に届く声が全員ぶんになる。** 従来は★1〜3の声しか店内に残らなかった。
  案Iでは★5の人が何を良いと思ったかも店に残る。

### 類似文面の実測（2026-08-23、実際にAPIを叩いて計測）

| 条件 | 類似度（3文字組の重なり） | 見た目 |
|---|---|---|
| 現行のまま（★5・タグ2つ・自由記述なしで5回） | 中央値 **0.32** / 最大 0.44 | 5件とも「スタッフ→料理→また来たい」で骨格が同一 |
| 書き方（長さ・書き出し・口調）を振り分けて5回 | 中央値 **0.14** / 最大 0.17 | 毎回変わる |

対策は3つ。①本人の言葉を主原料にする（＝案Iにすると自動的に手に入る。最大の対策）
②書き方を振り分ける ③出す前に直近の下書きと照合して似すぎていたら書き直す。

### ⚠ 実害が出ている（2026-08-26 判明）

**現行版が入っている FROMA の Google 口コミに、第三者から「ここはステマをやっている」と書かれた。**
おそらく **AIっぽい感想文のような文章**が並んでいたため。

- Googleの自動検出に引っかかるより先に、**人間の読者に見抜かれていた**
- ツールが原因で店が疑われるのは、上の製品思想の真逆
- したがって **「AIが書いた文章に見えないこと」自体を品質基準に置く**。
  対策①②③は「あったほうがいい改善」ではなく、**必須**である

---

## 6. 正直なトレードオフ（隠さない前提で設計した）

- **Googleへの送客数は減る可能性がある。** ★4〜5を自動的にGoogleへ流していたぶんが、本人の選択になるため。
- かわりに得るもの：**合法性（＝レビュー全消し・警告バナーのリスク回避）** と、**全員ぶんの声**。

---

## 7. 公式サイトで言ってはいけないこと（最重要）

サイトに書いた文言は、そのまま **「gatingを目的とした製品である」証拠** になる。以下は禁止。

- ✕「低評価をブロックします」「悪い口コミがGoogleに載りません」
- ✕「★4以上のお客様だけGoogleに誘導します」
- ✕「ネガティブな声は店内で受け止めるので、Googleの評価が上がります」
- ✕「評価を選別」「フィルタ」を想起させる語

### 言えること

- ○「お客様が、感想の宛先を自分で選べます」
- ○「全員ぶんの声が、お店に届きます」
- ○「Googleの規約に沿った設計です」（2026年4月の運用強化に対応、と言い切れる）
- ○「AIが、お客様自身の言葉を清書します」
- ○「ご意見箱2.0 — ご意見は、店長が直接読みます」（プロダクト思想として決めた言い方）

**訴求の軸になりうる一文**：「振り分けない。選ぶのはお客様。だから全員の声が届く。」
規約・製品価値・差別化の3つを同時に満たす。

### 見せ方のアイデア（2026-08-28 天真）

**文章で説明せず、2つのジャーニーを動く形（動画か操作できるデモ）で並べる。**

- **満足したお客様**：次々にアンケートが現れて答える → AIが文章を生成 → 店舗かGoogleかを選択 → **Googleで広めてくれる**
- **不満だったお客様**：次々に答えて悪い評価 → 悪かった点を選ぶ → 任意で文章も書ける → 店舗かGoogleかを選択 → **店長が分かってくれるならいいか**

2本が並ぶこと自体が「選別せず、選択させる」の証明になる。説明ではなく体験で伝える。
