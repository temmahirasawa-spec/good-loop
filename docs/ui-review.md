### Q1. 押しても何も起きないボタンを、どうしますか？

特に「請求履歴をすべて見る」は緑の大きなボタンなので、押されない方が不自然です。

- **A ★ 項目ごと隠す** — 準備ができた機能だけを出す。画面がすっきりする
- **B グレーにして「準備中」と添える** — 将来ここに機能が来ると伝わる
- **C 押したら「近日公開」と出す** — 期待させて裏切るので、私はおすすめしません

### Q5. 「1つ選ぶ」部品の使い分けを、何を基準に決めますか？

いま同じ「1つ選ぶ」操作に、タブ・ピル・ドロップダウンの3種類が混ざっています。
使う人は3回おぼえ直すことになります。**ここが決まらないと、置き換えても手戻りになります。**

- **A ★ 選択肢の数で決める**
  - 2〜4個で常に見せたい → セグメント（例：期間）
  - 5個以上、または将来増える → ドロップダウン（例：店舗・業態）
  - 画面そのものの切り替え → PCはタブ／SPはリスト
- **B 役割で決める** — 絞り込みは全部ドロップダウン、画面の切り替えは全部タブ。おぼえることは少ないが、期間の4つ並びもドロップダウンになり、ワンタップで切り替えられなくなる
- **C 決まりを作らず、今のまま個別に判断する**

### Q10. 消える操作に、取り消しを用意しますか？
