## 1. 一文の定義

> **全員が答えるのは★と話題の2問だけ。書きたい人にだけ、選んだ話題ごとの欄を渡す。
> AIは書いている途中には出てこず、最後に各欄の言葉を「つなげる」だけ。AIが足した文字には色を付けて見せる。**

## 3. 画面と流れ（2026-09-28 版）

```
① 評価：店のロゴ・進み具合・「所要時間は約1分です」・★5つ（タップで塗る。弾むのを見てから自動で次へ）
②以降の上：左上に「もどる」／真ん中に店のロゴ／下に4段の進み具合
② 印象に残ったことはありますか？（2カラム・6つ・いくつでも・選ばなくても進める）→［次へ］
③ この感想を、どこに届けますか？（2枚の扉。同じ大きさ・同じ形・同じ言い方。並び順は★によらず固定）
     ┌ [Googleのイラスト] Googleマップに投稿／だれでも読めます ┐  ┌ [お店のイラスト] お店にだけ届ける／お店の人だけが読みます ┐
     │［文章も書く］（塗り）                                    │  │［文章も書く］（塗り）                                     │
     │［★だけで評価する］（枠）                                 │  │［★評価だけを届ける］（枠）                                 │
     └──────────────────────────────┘  └───────────────────────────────┘
④a ★だけで評価する：あなたの評価 ★★★★☆ ／ Googleの画面で★を選んで「投稿」を押すと完了 →［Googleマップを開く］
④b 書く：「Googleに載せる感想を書く」（お店なら「お店に届ける感想を書く」）
     欄＝②で選んだ話題（選んだ順）＋「その他（自由記入）」。各5行
     欄の下に「完成した文章」（AIがつなげたもの・足した文字に色）。元の言葉のまま／直す
     Google：①この文章をコピー ②Googleマップを開く（コピー後に押せる） ③Googleの画面で★を選び、クチコミ欄に貼り付けて投稿
     お店：［この文章をお店に届ける］
④c ★評価だけを届ける：お店にとどく内容（★・印象に残ったこと）→［とどける］
⑤ 完了（店のロゴとお礼）
```

**タップ数（v4 と同じ数え方）**

| 経路 | タップ数 |
|---|---|
| ★だけでGoogleへ | 4（★・次へ・★だけで評価する・Googleマップを開く） |
| ★評価だけをお店へ | 4（★・次へ・★評価だけを届ける・とどける） |
| 書いてGoogleへ | 5＋書く操作（★・次へ・文章も書く・この文章をコピー・Googleマップを開く） |
| 書いてお店へ | 4＋書く操作（★・次へ・文章も書く・この文章をお店に届ける） |

- 欄の名前は「料理・ドリンクについて」のように**話題だけ**を書く（「良かった点」だと★が低い人が書きにくい。8/28 の「★で問いを変えない」とも合わせた）
- 欄のプレースホルダは**静的な問い**（話題ごとに3問を回す。`lib/survey/v5-topics.ts`）。**書いている途中にAIは話しかけない**
- 空いている欄があってよい。注記：個人が特定できることは書かない／（Googleのとき）書いた文章は、お店にも届きます

## 4. つなげる（AIの役割はここだけ）

- 書く手が止まって約1.2秒たつと、**文字が変わった欄だけ**を「整える」AI（v4 の `/api/survey/polish`）に並列で渡す。渡すのは**その欄の文字列だけ**（★・話題・店名は渡さない）。
  欄ごとの結果は覚えておき、同じ文字列では頼み直さない。日本語入力の変換中は頼まない。4文字未満の欄はAIに渡さず、句点だけ足す
- 返ってきた1文は、v4 の検査層（`lib/survey/polish-guard.ts`）を**サーバー側で**通ったものだけ。AIが足せるのは許可した助詞と句読点だけ
- 検査に落ちた欄・通信に失敗した欄は、**本人の言葉のまま**（句点だけ足す）でつなげる。1つもAIが整えられなければ「AIがつなげました」とは出さない
- **AIが足した文字に色を付ける**（`lib/survey/insertions.ts`、最長共通部分列）。「元の言葉のまま使う」でいつでも戻せる。「直す」で本人が編集している間は、上の欄を変えても反映しない
- **コピーできない端末**（アプリ内ブラウザなど）では、長押しでのコピーを案内し、②Googleマップを開くを押せるようにする（先へ進めなくならないように）
- Googleのときは「あなたの評価 ★★★★☆」を添える。「同じ数の★を選んでください」とは書かない（Googleでの評価の中身に触れないため）

## 5. 実測（2026-09-26、/demo/v5 を検品用ビルドで実際に操作）

改訂版の実測は §5-2。改訂前（問いを返すAI）の実測は記録として §5-1 に残す。

### 5-1. 改訂前：問いを返すAI（外した）

- 最初の問いは最後の入力から約2.5〜2.8秒。例「今日は天気が良く窓際の席だったので」→「窓からはどんな景色が見えましたか？」
- 10秒止まると別の角度の問いに替わり、さらに10秒で「ここまでで投稿できます」
- 直したこと：問いが30字を超えて捨てられる／「何か参考になったことはありますか？」「何か行動に移しましたか？」（良い前提・実質はい／いいえ）
- 残った課題：「その船はどのくらいの時間かけて通っていきましたか？」のような細かすぎる問い
- **天真の iPhone 実機での所感：「割り込まれてうっとうしい」「適切な問いとは限らない」→ 外した**

### 5-2. 改訂後：話題ごとの欄＋つなげる

## 8. 見た目と動き（2026-09-28。`app/demo/v5/v5.css`）

Webサイト v2（`~/Dev/Websites/UTUTU/GOOD_LOOP_Official_worktrees/v2-rebrand`、`design/v2/palette.json`・`motion/v2/tokens.ts`）から借りたもの。

- **色**：背景は生成り `#FAF6EC`、主ボタンは墨（`--product-color-text-primary` と同じ #233029）の塗りに白い文字、★は黄 `#FFBC11` に墨の線。
  緑は業態テーマの `--review-accent-*` のまま（選んだ話題の面・進み具合・AIが足した文字）。
  ⚠ **生成り・★の黄・影の3色は Figma の変数に無い。** `.v5` の下に試作専用の変数として置いた。本番化の前に Figma に登録する
- **形**：押せるものは丸いピル（999px）、枠は墨の2px、カードは角丸20px。影はぼかさず右下にずらす（届け先のカード・完成した文章・お店へのカードだけ）
- **動き**：着地（上から24px・0.96倍 → 0.5秒・pop）、タップ（0.96倍に沈んで pop で戻る）、★（黄色い輪が2つ広がり、★が左から70msずつ弾む）、
  判子（1.35倍 → 1、チェックとAIが足した文字）。`prefers-reduced-motion` ではすべて止める
- **書体**：LINE Seed JP（Figma とWebサイトが使っている）。`next/font/google` の一覧に無いので、`page.tsx` の `<link>` で Google Fonts から読む（本番化で使う文字だけに絞る）
- **Webサイトの決まりで守ったもの**：強い色は使いすぎない、遊びは2〜4か所、文字に緑・黄を使わない、白い文字は墨の上だけ
